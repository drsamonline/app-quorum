Quorum

Signed votes, a tally that names what it rejected, and a root anyone can recompute.

about

There is no camera and no QR scanner here. A vote payload is text — the string a QR would carry — and the root is a short string you can read aloud. Signing is a keyed checksum, not a cryptographic signature, and the page says so.

        Quorum counts valid votes only, names every vote it rejects, and gives a root that a second device can recompute character for character. Signing is a keyed checksum, not a cryptographic signature — it catches an edited payload, and it is not a security guarantee.
