Quorum

Signed votes, a tally that names what it rejected, and a root anyone can recompute — character for character.

Open Quorum

There is no camera and no QR scanner here, and signing is a keyed checksum, not a cryptographic signature. A vote payload is text — the string a QR would carry — and the root is eight characters you could read aloud. It catches an edited payload; it is not a security guarantee, and this page will not pretend otherwise.

Status Built and working: votes signed with a keyed checksum; a tally that counts valid votes only and names every vote it rejects; a root over the payloads that a second device recomputes and compares; and a payload string per vote, which is what a QR would carry.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: a camera, a QR scanner, and real cryptography. The payloads are plain text and the signature is a checksum.

What it does

  • Casts a vote — for, against or abstain — signed with the voter's key.
  • Verifies each vote against the key its voter published, and rejects an edited one by name.
  • Gives a root over the payloads; a second device recomputes it and the two strings must match exactly.
  • Exchanges votes as single-line payloads — the string a QR would carry.

What it will not do

  • Count an invalid vote. The tally is the number of valid signed votes.
  • Drop a rejected vote silently. It is named, with the reason.
  • Claim cryptographic security. The signing is a keyed checksum and the page says so.
  • Use the internet. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputNo motion, no voter, no choice, a nonsense choice, no key, a payload that is not a vote — each refused with the field named.
A tampered voteRejected, named, and left out of the tally — and the root changes, so the two devices disagree visibly.
No networkNothing changes; there is no network code.
Storage full or unavailableNOT SAVED, and the ballot on screen is unchanged.
Corrupt saved stateReported and offered for export; never replaced with an empty ballot — that looks like nobody voted.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
